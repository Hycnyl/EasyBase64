# EasyBase64 1.0.0

Developers: Orbis and Codex. Requires Android 12 (API 31) or later; English and Simplified Chinese are included.

- Base64 encoding and decoding of arbitrary files, with multi-file and folder batches.
- Standard / URL-safe alphabets, padding, line wrapping, line endings and CERTIFICATE text envelopes.
- Strict end-of-input validation, separate output folders, retries, cancellation and per-file records.
- Material You themes and phone / wide layouts; no app network permission.

Install `EasyBase64-1.0.0-universal.apk`; no CPU architecture selection is needed.

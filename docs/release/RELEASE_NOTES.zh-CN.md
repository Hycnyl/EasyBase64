# EasyBase64 1.0.0

开发者：Orbis 和 Codex。支持 Android 12（API 31）及以上，简体中文 / English。

- 任意文件的 Base64 编码与解码；多选文件和目录批处理。
- Standard / URL-safe、padding、折行、换行及 CERTIFICATE 文本包装选项。
- 严格尾部验证、独立输出目录、失败重试、取消和逐文件记录。
- Material You 动态主题、手机 / 大屏布局，无应用网络权限。

安装 `EasyBase64-1.0.0-universal.apk`，无需选择 CPU 架构。
